## Cross-Cutting Findings

**The QC gate matters.** Every state that predated the `legislative-reviewer` 80/100 gate had real, confirmable gaps — not hypothetical rigor concerns. This validates Peter's original instinct to re-run the early batch rather than treat it as settled.

**Checking for "wrong" isn't the same as checking for "missing."** The P4→P5 correction cycle is the clearest lesson from this session: a completeness audit (does every condition/responder-type combination the research confirms exist, actually exist as a row?) is a different check than a discrepancy audit (does existing content match the research?). P4 only did the latter. **The other 5 states (CA, NY, FL, IL, PA) have not yet been checked for the same completeness-gap failure mode found in TX** — flagged as an open issue in `bob.md`.

**The CSV/RDS pipeline is now genuinely dead weight.** Five correction passes (P1–P5) have all patched the JSON directly; none have touched the CSV. It's ~32+ rows out of sync and drifting further with each pass. Worth a decision (retire vs. restore) before it becomes actively misleading to anyone who assumes it's current.
